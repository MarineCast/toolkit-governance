# Documentation site

Install `.[docs]` and run `mkdocs build --strict` from the checkout. Use `mkdocs serve` for a local preview. MkDocs navigation covers the current product workflow and public families; provider DATA_SOURCES.md files stay in the source tree and are linked directly.

Maintain README as the entry point, family pages for scientific meanings, Parquet products for output contracts, configuration/API for execution and coverage for refresh/qualification. Avoid duplicating historical build logs or acquisition inventories in the user guide. Preserve incoming source-note anchors when reorganizing canonical contracts.
